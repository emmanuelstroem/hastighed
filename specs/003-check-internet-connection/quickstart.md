# Quickstart: Connectivity & Country Context

1. Launch the app; ensure Location permission is requested.
2. Observe connectivity indicator: online/offline and network type (Wi‑Fi/Cellular).
3. If offline, connect to internet and verify the indicator updates within seconds.
4. Move location (simulator) across a border; verify country switches only after stability window expires or with manual override.
5. Initiate a download on Wi‑Fi; confirm starts without prompt.
6. Initiate a download on Cellular with a large file; confirm prompt appears and allows proceed/cancel.
7. Pause and resume a download; verify progress resumes from last state.
8. Cancel a download; verify partial file cleanup.
